UseThisModel MCP

Give Hermes, Codex, OpenCode, Pi, and other MCP clients compact, source-backed answers about exact model routes, prices, capabilities, compatibility, deals, releases, benchmarks, and plans.

https://usethismodel.codefiction.net/mcp

CONNECT

Current client formats

Hermes Agent

Add to ~/.hermes/config.yaml, then run /reload-mcp.

mcp_servers:
  usethismodel:
    url: "https://usethismodel.codefiction.net/mcp"
    trust: untrusted
    tools:
      resources: true

Codex CLI

Use the CLI, or add the equivalent [mcp_servers.usethismodel] entry to ~/.codex/config.toml.

codex mcp add usethismodel \
  --url https://usethismodel.codefiction.net/mcp

OpenCode v2

Add to opencode.jsonc. This public server does not use OAuth.

{
  "mcp": { "servers": {
    "usethismodel": {
      "type": "remote",
      "url": "https://usethismodel.codefiction.net/mcp",
      "oauth": false
    }
  }}
}

Pi

Add to ~/.pi/agent/mcp.json or project .pi/mcp.json, then run pi mcp list.

{
  "mcpServers": {
    "usethismodel": {
      "url": "https://usethismodel.codefiction.net/mcp",
      "exposure": "direct"
    }
  }
}

PRIVACY & SECURITY

Bounded public catalogue

The server cannot write catalogue data and exposes no database query tool. It returns only public model, provider, offer, benchmark, plan, and compatibility records. Application secrets, provider API keys, environment variables, Git credentials, and private Hermes configuration are outside every schema and response. The public transport validates inputs, caps result sizes and request bodies, and applies per-client rate protection.
